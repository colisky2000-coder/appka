# Грабли

- 2026-09-25 — `auto_migrate` (backend/db.py) только добавляет колонки: удалённое из модели поле остаётся в БД (например, `offer_links.form_enabled`), это нормально.
- 2026-09-25 — Таблицы из `OBSOLETE_TABLES` в backend/db.py удаляются при каждом старте вместе с данными: не добавлять туда то, что нужно сохранить.
- 2026-09-25 — Разделы тарифа хранятся JSON-списком; неизвестные ключи отбрасывает `features.parse`, поэтому удаление раздела из `FEATURES` не ломает старые тарифы.
- 2026-09-25 — `start.bat` ставит `SEED_DEMO=1`: на пустой базе появятся демо-офферы, статьи и новости.
- 2026-09-25 — Данные админки пользователя лежат только у него локально в `cabinet/instance/cabinet.db` (в .gitignore); при обновлении кода эту папку не трогать.
- 2026-09-25 — В облачном контейнере Claude Google Fonts отдаёт ERR_CERT_AUTHORITY_INVALID, а teletype.in / telegra.ph недоступны (403 прокси): это окружение, не баг кода.
- 2026-09-25 — `users.email` в коде — `User.login` (логин для входа; у старых аккаунтов это email). Колонку не переименовывать.
- 2026-09-25 — Убирая поле из модели, оставляй его в модели с default, если колонка NOT NULL: в старых базах она без значения по умолчанию и INSERT падает (так было с `offer_links.form_enabled`, `tariffs.invite_*`, `users.tg_link_code`).
- 2026-09-25 — Кабинет может жить в подпапке (URL_PREFIX): во фронтенде и в адресах от сервера (обложки, скачивание, картинки в тексте) только относительные пути без ведущего `/`; абсолютные ссылки — через `request.url_root`/PUBLIC_URL, не `host_url`.
- 2026-09-25 — Секрет вебхука Telegram выводится из токена (`telegram.webhook_secret()`), в базе не хранится — одинаков во всех процессах gunicorn/Passenger.
- 2026-09-25 — Класс с `display` перебивает атрибут `hidden` — в styles.css стоит `[hidden] { display: none !important; }`, не убирать.
- 2026-09-25 — Шорткаты редактора («# », «- », «1. ») через execCommand в Chrome ломают структуру (список внутри абзаца) — сделаны прямой заменой DOM-блока.
- 2026-09-25 — В контейнере Claude Playwright запускать с `executable_path="/opt/pw-browsers/chromium-1194/chrome-linux/chrome"`; help.sprinthost.ru и другие .ru-сайты недоступны (прокси).
- 2026-09-27 — В контейнере Claude `pkill -f wsgi.py` убивает и саму команду bash (exit 144): сервер запускать с записью PID (`echo $! > server.pid`) и гасить по нему.
- 2026-09-27 — `offsetTop` у элемента с `position: relative`-родителем считается от родителя, а не от контейнера: для линии роадмапа координаты берутся через `getBoundingClientRect`.
