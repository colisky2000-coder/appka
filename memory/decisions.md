# Решения

- 2026-09-25 — Удалили «Закуп трафика» (продажа строк с контактами) и публичную форму `/f/<код>` (ИНН, ФИО, телефон): пользователю не нужны; старые таблицы `traffic_rows`, `purchases` стираются при старте.
- 2026-09-25 — Пополнение баланса перенесено на страницу «Подписка» (`GET /api/balance`, раздел `billing`).
- 2026-09-28 — Вход только через Telegram по коду: «Войти через Telegram» → бот присылает код → ввод на сайте (не автовход по кнопке — пользователь хочет именно код). Код получает только зарегистрированный Telegram или новичок по действующей ссылке-приглашению; тариф/программа — от ссылки (и для уже зарегистрированных тоже). Паролей у пользователей нет, логин = @username (или tg<id>). Вход по паролю оставлен запасным для администратора и для запуска без бота.
- 2026-09-25 — Регистрация только по ссылке-приглашению от админа; на тариф можно несколько ссылок, у каждой лимит регистраций.
- 2026-09-27 — Шрифты: крупный текст — Benzin Semibold, мелкий — Yandex Sans (файлы из архива пользователя); акцентный цвет — синий Apple (#0071e3 кнопки, #0066cc ссылки), красный больше не используем.
- 2026-09-25 — Токен бота хранится только в `.env` / переменных хостинга (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`).
- 2026-09-25 — Хостинг: Sprinthost (cp.sprinthost.ru), домен schooloftraff.ru, на нём уже другой сайт. Кабинет открывается по секретному подпути (например /secretniyadresstest), существующий сайт не трогаем.
- 2026-09-25 — Описание уроков и текст статей — HTML из своего визуального редактора (static/js/editor.js, без библиотек); сервер чистит по белому списку (backend/richtext.py). Старые тексты в простом формате остаются и форматируются как раньше. Импорт из Google Docs не делаем — пользователю нужно, чтобы редактор работал «как там».
- 2026-09-25 — «Открытая регистрация» в настройках убрана; ручное создание пользователя админом оставлено.
- 2026-09-27 — Название платформы: School of Traff, знак «ST» на синем; админ меняет их в «Настройки и тексты → Бренд» (одно поле `brand_name`, `brand_accent` убран, старые значения склеивает `settings.migrate_brand`).
- 2026-09-27 — Дизайн по мотивам Apple («белая галерея»): карточки #f5f5f7 без рамок и теней, радиус 28px, кнопки-пилюли, только светлая тема; применён в styles.css, описан в cabinet/DESIGN.md.
- 2026-09-27 — Новый знак: фиолетовый размытый шар от пользователя (`static/img/logo.png`, фавикон `static/img/favicon.png`), буквы из настроек — белым поверх; синий акцент кнопок остаётся.
- 2026-09-27 — Роадмап вертикальный: кольца прогресса шагов, светящаяся синяя линия до текущего шага и пунктир дальше, пин «Вы здесь», крупная карточка текущего шага, раскрытие остальных по клику, флажок с подписью `learn_finish_text`. Отдельная панель шага и «Назад/Следующий шаг» убраны.
- 2026-09-27 — Пользователю не нужны скрины: изменения сразу применять в коде (правило «сначала демо-скрин» отменено).
- 2026-09-28 — Кнопка поддержки в углу ведёт на t.me/Pasha_Helper (настройка `support_url`, пусто — кнопки нет).
- 2026-09-28 — После урока: «Урок пройден» ведёт на роадмап; внизу урока — «В список уроков» и «К роадмапу», «Следующий урок» убран.
- 2026-09-28 — Редактор: у картинки ширина 25/50/75/100% или тянуть за уголок (шаг 5%), выравнивание слева/справа с обтеканием, подпись; у ссылки — изменить/убрать; блок «Важно» (<aside>). Размер хранится в `data-w`, сервер сам ставит `style="width:N%"`.
