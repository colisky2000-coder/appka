# Решения

- 2026-09-25 — Удалили «Закуп трафика» (продажа строк с контактами) и публичную форму `/f/<код>` (ИНН, ФИО, телефон): пользователю не нужны; старые таблицы `traffic_rows`, `purchases` стираются при старте.
- 2026-09-25 — Пополнение баланса перенесено на страницу «Подписка» (`GET /api/balance`, раздел `billing`).
- 2026-09-25 — Без почты: регистрация — по ссылке-приглашению + одноразовый код из Telegram-бота (как подтверждение email); вход — по логину и паролю. Код — только для регистрации.
- 2026-09-25 — Логин придумывает сам человек при регистрации, по умолчанию подставляется его @username из Telegram; у старых аккаунтов логин = их email.
- 2026-09-25 — Забытый пароль восстанавливает администратор в карточке пользователя (сброс кодом из бота не делаем).
- 2026-09-25 — Регистрация только по ссылке-приглашению от админа; на тариф можно несколько ссылок, у каждой лимит регистраций.
- 2026-09-25 — Шрифты: крупный текст — Benzin Semibold, мелкий — Yandex Sans (файлы из архива пользователя); акцентный цвет — красный.
- 2026-09-25 — Токен бота хранится только в `.env` / переменных хостинга (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`).
- 2026-09-25 — Хостинг: Sprinthost (cp.sprinthost.ru), домен schooloftraff.ru, на нём уже другой сайт. Кабинет открывается по секретному подпути (например /secretniyadresstest), существующий сайт не трогаем.
- 2026-09-25 — Описание уроков и текст статей — HTML из своего визуального редактора (static/js/editor.js, без библиотек); сервер чистит по белому списку (backend/richtext.py). Старые тексты в простом формате остаются и форматируются как раньше. Импорт из Google Docs не делаем — пользователю нужно, чтобы редактор работал «как там».
- 2026-09-25 — «Открытая регистрация» в настройках убрана; ручное создание пользователя админом оставлено.
