# Выкладка на Sprinthost по секретному адресу

Цель: кабинет открывается по адресу `https://schooloftraff.ru/secretniyadresstest/`,
а сайт, который уже работает на `schooloftraff.ru`, остаётся как есть.

**Что появится на хостинге** (текущие файлы сайта не меняются):

```
~/schooloftraff.ru/
  public_html/                    ← текущий сайт, НЕ трогаем
    secretniyadresstest/          ← НОВАЯ папка, внутри только файл .htaccess
  cabinet/                        ← НОВАЯ папка: код кабинета и ваша база (вне public_html — снаружи не скачать)
  venv/                           ← НОВАЯ папка: Python и библиотеки
```

> Точные пути смотрите в панели cp.sprinthost.ru → «Файловый менеджер». Ниже `ЛОГИН` — ваш логин
> на хостинге, а `schooloftraff.ru` — папка сайта. Если у вас папка сайта называется иначе
> (например, `domains/schooloftraff.ru`), подставьте свою.
>
> Перед началом на всякий случай сделайте резервную копию сайта в панели («Резервные копии»).

## 1. Подготовьте файлы на компьютере

1. Скачайте свежий код (ветку с кабинетом) и возьмите из него папку `cabinet`.
2. **Ваши данные.** Закройте окно `start.bat`, если кабинет запущен (чтобы база записалась целиком),
   и найдите файл `cabinet/instance/cabinet.db` в папке, где вы запускали кабинет. Это вся ваша админка:
   пользователи, уроки, материалы, картинки. Его нужно положить в ту же папку на хостинге.
3. Упакуйте папку `cabinet` (вместе с `instance/cabinet.db`) в zip.

## 2. Загрузите на хостинг

1. Панель → «Файловый менеджер» → откройте папку сайта `schooloftraff.ru` (уровень, где лежит `public_html`).
2. Загрузите zip и распакуйте: должна получиться папка `schooloftraff.ru/cabinet`
   (рядом с `public_html`, **не внутри** неё).
3. Проверьте, что есть файл `cabinet/instance/cabinet.db`.

## 3. Установите Python-окружение

Нужен доступ по SSH (панель → «SSH» — включите, там же логин и адрес для входа).
Подключитесь и выполните по очереди:

```bash
cd ~/schooloftraff.ru
python3 --version                       # нужна версия 3.9 или новее
python3 -m venv venv
venv/bin/pip install -r cabinet/deploy/sprinthost/requirements.txt
```

Если `python3 --version` показывает версию ниже 3.9 — в панели Sprinthost можно выбрать
версию Python (раздел про Python/Flask); создайте окружение той версией, например `python3.11 -m venv venv`.

## 4. Настройки (.env)

1. Скопируйте `cabinet/deploy/sprinthost/env.txt` в `cabinet/.env`.
2. Впишите токен бота и его имя (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`) — токен выдаёт @BotFather.
   Токен не пересылайте в чатах — только в этот файл.
3. Если выбрали другой секретный адрес — поменяйте `URL_PREFIX` и `PUBLIC_URL`
   (и назовите так же папку из шага 5).

## 5. Подключите адрес

1. В `public_html` создайте папку `secretniyadresstest`.
2. Скопируйте в неё файл `cabinet/deploy/sprinthost/htaccess.txt` и переименуйте в `.htaccess`.
3. Откройте `.htaccess` и замените `ЛОГИН` на ваш логин (и путь, если папка сайта называется иначе).

Больше в `public_html` ничего не меняется.

## 6. Проверка

1. Откройте `https://schooloftraff.ru/secretniyadresstest/` — появится вход в кабинет.
   Войдите тем же логином и паролем, что и у себя на компьютере.
2. Админка → «Обзор» → «Telegram-бот»: при запуске вебхук подключается сам, кнопка
   «Подключить вебхук» — подключить заново.
3. Админка → «Приглашения» → создайте ссылку и откройте её в другом браузере: должен
   появиться шаг «Получить код в Telegram», бот пришлёт код.
4. Основной сайт `https://schooloftraff.ru/` должен открываться как раньше.

## Обновление кода потом

Замените файлы в `~/schooloftraff.ru/cabinet`, **кроме** папки `instance` (там база) и файла `.env`.
Затем перезапустите приложение:

```bash
mkdir -p ~/schooloftraff.ru/cabinet/tmp && touch ~/schooloftraff.ru/cabinet/tmp/restart.txt
```

## Если что-то не работает

- **Ошибка 500 или «Internal Server Error»** — панель → «Логи» (error.log). Частые причины: неверный
  путь в `.htaccess`, не установлены библиотеки (шаг 3), старая версия Python.
- **Открывается основной сайт вместо кабинета** — проверьте, что `.htaccess` лежит именно в
  `public_html/secretniyadresstest/` и называется с точкой в начале.
- **Страница без стилей** — адрес должен заканчиваться на `/`: `…/secretniyadresstest/`.
- **Бот не присылает код** — проверьте токен и имя бота в `.env`, затем «Подключить вебхук» в админке.
  Сайт должен открываться по `https://`.
