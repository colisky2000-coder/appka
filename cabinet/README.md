# Личный кабинет партнёра

Полноценный кабинет: сервер на Flask, база данных, вход по логину и паролю, кабинет пользователя
и админка для управления всем содержимым. Интерфейс — обычные HTML/CSS/JS, сборка не нужна.
Шрифты: крупный текст — Benzin, мелкий — Yandex Sans (лежат в `static/fonts`), акцентный цвет — красный.

## Что умеет

**Пользователь**
- регистрация — только по ссылке-приглашению от администратора, без почты: бот в Telegram присылает
  код подтверждения, затем человек придумывает логин (по умолчанию — его @username) и пароль;
- вход по логину и паролю, смена пароля, список активных сессий с завершением;
- дашборд: топ участников (30 дней / всё время), команда, своя статистика, новости с отметкой «прочитано»;
- база знаний: статьи по категориям (можно закрыть тарифом), файлы и ссылки;
- баланс: заявка на пополнение, оплата тарифа с баланса;
- партнёрка: каталог офферов (ставка с учётом тарифа), избранное, персональные ссылки
  через наш редирект `/go/<код>` (реальный адрес скрыт, переходы считаются);
- заявки: создание, фильтры, статусы и суммы, вопросы по заявкам;
- статистика: переходы/заявки/деньги по дням, офферам или субметкам, выгрузка CSV;
- доходы: доступно к выводу, в холде, в работе, выплачено, движение баланса;
- поддержка: обращения с перепиской;
- тарифы: покупка/продление с баланса;
- уведомления в Telegram (если настроен бот).

**Обучение** (раздел включается в тарифе)
- роадмап: линия шагов (на телефоне — вертикальная), в каждом шаге задачи-галочки, прогресс и кнопка «Продолжить»;
- уроки: карточки с обложками, видео по ссылке (YouTube, RuTube, VK Видео, Vimeo, Дзен) играет прямо на сайте,
  описание из визуального редактора, задачи «что сделать после урока», кнопка «Урок пройден → дальше»;
- материалы: крупные карточки статей и файлов с превью (размер подстраивается под экран), привязанные к программе.

**Визуальный редактор** описания уроков и текста статей — пишешь прямо в поле, как в Google Docs или Teletype:
заголовки, жирный/курсив/подчёркнутый/зачёркнутый, списки, цитаты, ссылки, разделитель, картинки
(кнопкой, вставкой из буфера Ctrl+V или перетаскиванием), видео по ссылке. Быстрое оформление в начале
строки: `# ` — заголовок, `- ` — список, `1. ` — нумерованный, `> ` — цитата. Картинки хранятся в базе;
HTML перед сохранением чистится по белому списку (`backend/richtext.py`).

**Тарифы = набор разделов.** У каждого тарифа галочки: дашборд, обучение, мануалы, офферы, избранное,
заявки, статистика, доходы, поддержка, подписка. Профиль и пароль доступны всегда. К тарифу привязывается
программа обучения. Кнопка «Смотреть» в списке тарифов показывает сайт глазами этого тарифа.

**Приглашения.** Зарегистрироваться можно только по ссылке `/join/<код>` из «Админка → Приглашения».
На каждый тариф — сколько угодно ссылок; у ссылки заметка (для кого), лимит регистраций, срок доступа
к тарифу и дата, до которой она работает. Видно, сколько человек и кто именно пришёл по ссылке.
Уже зарегистрированный человек по ссылке активирует тариф.

**Превью** у статей, файлов, уроков и программ: загрузить картинку, дать ссылку на неё или подтянуть
автоматически со страницы-источника (Teletype и большинство сайтов, YouTube, RuTube).

**Администратор** (раздел «Админка» в меню)
- пользователи: роли, тарифы, доступ к ссылкам, блокировка, баланс (+/−), новый пароль (если человек забыл свой), удаление;
- приглашения: ссылки на тарифы с лимитами и сроками;
- заявки: статусы, суммы, комментарии, массовая смена статуса, ручное добавление, CSV;
- ссылки: выдача адреса оффера по запросу пользователя, лимиты, отключение;
- обучение: программы, шаги роадмапа с задачами, уроки, выбор материалов программы; порядок — стрелками;
- офферы, статьи и файлы (где показывать: «Мануалы» и/или программы), новости (с рассылкой в Telegram), команда;
- тарифы: разделы-галочки, программа, ссылки-приглашения, просмотр глазами тарифа;
- пополнения: зачисление/отклонение заявок;
- поддержка: ответы на обращения;
- **настройки и тексты**: название, логотип, все тексты-пояснения на страницах,
  инструкция по оплате.

## Партнёрский API — заглушка

Выдача ссылок на офферы через внешний API ещё не подключена. Вся интеграция собрана в одном
файле `backend/partner_api.py`:

- `get_offer_link(user, offer)` — вернуть URL персональной ссылки (сейчас возвращает `None`);
- `sync_conversions()` — подтянуть статусы заявок (сейчас ничего не делает);
- `is_configured()` — вернуть `True`, когда интеграция готова.

Пока API нет, ссылка создаётся со статусом «запрошена», а админ вписывает адрес вручную
в «Админка → Ссылки». У оффера есть поле «ID во внешней системе» — его удобно использовать в API.

## Локальный запуск

**Windows:** установите Python с python.org (при установке отметьте «Add python.exe to PATH»),
затем дважды кликните `start.bat` в папке `cabinet`. Кабинет откроется в браузере,
вход — `admin@site.ru` / `admin12345` (пароль смените в «Сменить пароль»).

**macOS / Linux:**

```bash
cd cabinet
pip install -r requirements-dev.txt
ADMIN_EMAIL=admin@example.com ADMIN_PASSWORD=admin12345 SEED_DEMO=1 python wsgi.py
```

Откройте http://localhost:8000 и войдите под `ADMIN_EMAIL` / `ADMIN_PASSWORD`.
`SEED_DEMO=1` заполнит пустую базу примерами (офферы, статьи, новости).
Без `DATABASE_URL` данные хранятся в SQLite: `cabinet/instance/cabinet.db`.
Чтобы работала регистрация по приглашениям, создайте рядом с `wsgi.py` файл `.env`
(образец — `.env.example`) и впишите токен и имя Telegram-бота.

Тесты:

```bash
python -m pytest tests
# на Postgres:
TEST_DATABASE_URL=postgresql://user:pass@localhost/dbname python -m pytest tests
```

## Деплой (Render / Railway)

1. Создайте базу **PostgreSQL** и возьмите её адрес. На хостинге без Postgres данные
   (включая загруженные файлы — они хранятся в базе) пропадут при перезапуске.
2. Создайте веб-сервис из этого репозитория, корневая папка — `cabinet`
   (есть `Dockerfile` и `Procfile`, стартовая команда: `gunicorn wsgi:app`).
3. Переменные окружения (см. `.env.example`):
   - `DATABASE_URL` — адрес Postgres (формат `postgres://…` подходит как есть);
   - `ADMIN_EMAIL`, `ADMIN_PASSWORD` — первый администратор;
   - `PUBLIC_URL` — адрес сайта, например `https://cabinet.example.com`;
   - по желанию `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`.
4. Проверка работоспособности: `GET /healthz`.

Администратора можно создать и командой:

```bash
flask --app wsgi create-admin admin@example.com 'пароль'
```

### Telegram-бот

Бот нужен для регистрации (код подтверждения) и уведомлений. Создайте бота у @BotFather и задайте
`TELEGRAM_BOT_TOKEN` и `TELEGRAM_BOT_USERNAME` (в `.env` рядом с `wsgi.py` или в переменных хостинга).
- Локально (`python wsgi.py`, `start.bat`) бот сам забирает сообщения — ничего настраивать не нужно.
- На хостинге укажите `PUBLIC_URL` с `https://` — вебхук подключится при запуске
  («Админка → Обзор → Подключить вебхук» — подключить заново).

Кто зарегистрировался по приглашению, получает уведомления сразу. Старые аккаунты (например, админ)
привязывают Telegram в профиле кнопкой «Привязать через бота».

### Кабинет в подпапке сайта

Кабинет может работать не в корне домена, а по адресу вроде `https://site.ru/secret/`: задайте
`URL_PREFIX=/secret` и `PUBLIC_URL=https://site.ru/secret`. Все адреса во фронтенде относительные,
cookie ставится только на эту подпапку, поисковикам запрещено индексировать кабинет.
Выкладка на виртуальный хостинг Sprinthost рядом с уже работающим сайтом — [deploy/SPRINTHOST.md](deploy/SPRINTHOST.md)
(точка входа для Passenger — `passenger_wsgi.py`).

## Структура

```
cabinet/
  wsgi.py               точка входа (читает .env)
  passenger_wsgi.py     точка входа для Passenger (Sprinthost)
  deploy/               инструкция и шаблоны для Sprinthost
  backend/
    __init__.py         создание приложения, обработка ошибок, CSRF-защита
    models.py           таблицы базы данных
    api.py              API кабинета (/api/...)
    admin.py            API админки (/api/admin/...)
    public.py           /go/<код>, /join/<код>, вебхук Telegram
    services.py         общая логика: логины, приглашения, ставки, ссылки, статусы, топ
    bot.py              Telegram-бот: коды регистрации, привязка, вебхук и опрос
    richtext.py         очистка HTML из визуального редактора
    settings.py         список редактируемых текстов и настроек
    features.py         разделы сайта, которые включаются в тарифе
    media.py            превью-картинки, автоподбор со страницы, встраивание видео
    partner_api.py      ЗАГЛУШКА интеграции с партнёрским API
    telegram.py         отправка сообщений в Telegram
    auth.py             пароли, сессии, права доступа
    seed.py             тариф по умолчанию и демо-данные
  static/               интерфейс (index.html, styles.css, js/)
  tests/                автотесты API
```

Новый текст на странице удобно сделать редактируемым: добавьте строку в `SCHEMA`
в `backend/settings.py` — поле сразу появится в «Админка → Настройки и тексты»
и будет доступно во фронтенде как `App.cfg.settings.<ключ>`.

Схема базы создаётся и обновляется автоматически при запуске: новые таблицы создаются,
в существующие добавляются новые колонки, данные сохраняются. Переименование и удаление
колонок так не делается — для этого стоит подключить миграции (Alembic).
